P-01

Eye Gaze Wheelchair Control

Computer Vision · IoT · Assistive Tech

Hands-free wheelchair control via real-time iris tracking. MediaPipe FaceMesh (478 landmarks with iris refinement) extracts gaze vectors from both eyes, passed through a 4-stage smoothing pipeline: Kalman filter → 7-frame moving average → exponential smoothing → outlier rejection. 1.5s dwell time triggers Forward / Left / Right / Stop via Blynk HTTP API to ESP32 motor controller. Live dashboard: FPS, latency, gaze stability, head pose (pitch/yaw/roll), lighting quality, and camera distance. Supports both IP cameras and local webcams.

MediaPipe FaceMesh · 478 landmarks Kalman Filter OpenCV Blynk IoT ESP32 4-Stage Gaze Smoothing
